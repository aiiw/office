## listagg

**1.使用条件查询 查询部门为20的员工列表**

```
-- 查询部门为20的员工列表
SELECT t.DEPTNO,t.ENAME FROM SCOTT.EMP t where t.DEPTNO = '20' ;
```

2.使用  listagg() WITHIN GROUP ()  将多行合并成一行(比较常用)

```sql
SELECT
	T .DEPTNO,
	listagg (T .ENAME, ',') WITHIN GROUP (ORDER BY T .ENAME) names
FROM
	SCOTT.EMP T
WHERE
	T .DEPTNO = '20'
GROUP BY
	T .DEPTNO
```

```
XMLAGG 和 LISTAGG 是在 SQL 中用于聚合数据的两个不同函数，它们的主要区别在于输出的数据类型和适用场景。

数据类型和输出格式：

XMLAGG： XMLAGG 函数用于将查询结果聚合为一个 XML 类型的结果集。它返回的是一个 XML 类型的值，可以包含多个 XML 元素。
LISTAGG： LISTAGG 函数用于将多行数据聚合为一个单一的字符串。它返回的是一个普通的字符串，其中多个值用指定的分隔符连接起来。
适用场景：

XMLAGG： 适合于需要将数据以 XML 格式输出或者在 XML 处理中使用的场景。例如，当你需要生成一个包含多个元素的 XML 结构时，可以使用 XMLAGG 将多行数据合并为一个 XML 序列。
LISTAGG： 适合于需要将多行数据合并为一个逗号分隔的字符串的场景。通常用于生成简单的逗号分隔列表或者其他文本格式的输出。
示例比较：

使用 XMLAGG：

sql
SELECT 
    XMLAGG(XMLELEMENT(E, department || ', ')).EXTRACT('//text()') AS departments
FROM 
    employees;
这个示例将部门信息聚合为一个 XML 字符串，每个部门后面带有逗号。

使用 LISTAGG：

sql
SELECT 
    LISTAGG(department, ', ') WITHIN GROUP (ORDER BY employee_id) AS departments
FROM 
    employees;
这个示例将部门信息连接成一个逗号分隔的字符串，没有额外的 XML 结构。

总体来说，选择 XMLAGG 还是 LISTAGG 取决于你的数据处理需求和最终的输出格式。如果需要生成 XML 类型的输出或者在 XML 处理中使用，那么选择 XMLAGG 更为合适。如果只是简单地将多行数据合并为一个普通的字符串输出，那么 LISTAGG 是更合适的选择。
```
