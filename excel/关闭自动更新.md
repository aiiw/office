1. `Application.DisplayAlerts = False`：将警告对话框的显示设置为关闭。当设置为 False 时，Excel 将在执行某些操作时不显示任何警告或确认对话框。这可以避免用户在进行自动化处理时被打断。
2. `Application.ScreenUpdating = False`：将屏幕更新设置为关闭。当设置为 False 时，Excel 将不会更新屏幕上的任何内容，以提高代码的执行速度。这样可以在处理大量数据或执行复杂操作时提高性能。
3. `Application.AskToUpdateLinks = False`：将链接更新提示设置为关闭。如果您的工作簿中包含链接到其他文件或数据源的公式或对象，当设置为 False 时，Excel 将不会提示您更新链接，而是自动根据链接设置的规则进行更新。
4. `Application.Calculation = xlManual`：将计算模式设置为手动。当设置为 xlManual 时，Excel 将不会自动重新计算工作簿中的公式。这意味着只有在您明确要求时，Excel 才会重新计算公式。这可以提高处理大型工作簿时的性能。
