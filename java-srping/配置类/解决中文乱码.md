在SSM框架（Spring + Spring MVC + MyBatis）中，如果JSP页面显示中文乱码，可以通过以下几种方式解决：

1. **设置编码过滤器**：在web.xml中配置一个字符编码过滤器，确保请求和响应的字符编码一致。

   ```xml
   <filter>
       <filter-name>encodingFilter</filter-name>
       <filter-class>org.springframework.web.filter.CharacterEncodingFilter</filter-class>
       <init-param>
           <param-name>encoding</param-name>
           <param-value>UTF-8</param-value>
       </init-param>
   </filter>
   <filter-mapping>
       <filter-name>encodingFilter</filter-name>
       <url-pattern>/*</url-pattern>
   </filter-mapping>
   ```

2. **在JSP页面头部设置字符编码**：确保在JSP文件的头部设置正确的字符编码。

   ```xml
   jspCopy Code
   <%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>
   ```

3. **在Spring MVC配置中设置字符编码**：在Spring MVC的配置文件中设置字符编码。

   ```xml
   xmlCopy Code
   <mvc:annotation-driven>
       <mvc:message-converters register-defaults="true">
           <bean class="org.springframework.http.converter.StringHttpMessageConverter">
               <property name="supportedMediaTypes">
                   <list>
                       <value>text/html;charset=UTF-8</value>
                   </list>
               </property>
           </bean>
       </mvc:message-converters>
   </mvc:annotation-driven>
   ```

4. **数据库连接字符集设置**：确保数据库连接的字符集正确设置为UTF-8，以防止数据库中存储的中文乱码。

   ```
   xmlCopy Code<property name="connectionProperties" value="useUnicode=true;characterEncoding=utf8;"/>
   ```
