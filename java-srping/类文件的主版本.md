类文件的主要版本是指 Java 编译器用于生成类文件的版本号。每个 Java 版本都会对应一个特定的类文件主要版本号，用来标识编译器所生成的类文件的格式和特性。

在 Java 5 之前，Java 编译器生成的类文件的主要版本号一直为 49。从 Java 5 开始，每个主要版本引入了新的语言特性和功能，并相应地增加了类文件的主要版本号。

以下是一些常见的类文件主要版本号及其对应的 Java 版本：

- Java 1.1：主要版本号为 45
- Java 1.2：主要版本号为 46
- Java 1.3：主要版本号为 47
- Java 1.4：主要版本号为 48
- Java 5：主要版本号为 49
- Java 6：主要版本号为 50
- Java 7：主要版本号为 51
- Java 8：主要版本号为 52
- Java 9：主要版本号为 53
- Java 10：主要版本号为 54
- Java 11：主要版本号为 55
- Java 12：主要版本号为 56
- Java 13：主要版本号为 57
- Java 14：主要版本号为 58
- Java 15：主要版本号为 59
- Java 16：主要版本号为 60
- Java 17：主要版本号为 61

每个新版本的 Java 都会引入一些改进和新特性，而类文件的主要版本号则反映了这些变化。通常情况下，较新版本的 Java 编译器可以编译生成较旧版本的类文件，但较旧版本的 Java 运行时环境可能无法运行较新版本的类文件。
