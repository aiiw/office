1. **Bootstrap ClassLoader（启动类加载器）**：负责加载Java核心类库，如`java.lang`包中的类。这是Java虚拟机的一部分，通常由本地代码实现，无法直接获取其引用。
2. **Extension ClassLoader（扩展类加载器）**：负责加载Java的扩展库，如`javax`包中的类。它是Java虚拟机的一部分，通常由`sun.misc.Launcher$ExtClassLoader`类实现。
3. **Application ClassLoader（应用程序类加载器）**：也称为系统类加载器，负责加载应用程序类路径（Classpath）上的类，通常是开发者编写的Java类文件。它是`sun.misc.Launcher$AppClassLoader`类的实例。



除了这些类加载器之外，`sun.misc.Launcher` 类还包含一些其他的重要方法，如 `getSystemClassLoader()` 用于获取系统类加载器，以及 `getBootstrapClassPath()` 用于获取启动类路径等。

需要注意的是，`sun.misc.Launcher` 类位于 `sun.misc` 包中，而 `sun.misc` 包下的类通常是供 JDK 内部使用的，不建议在应用程序中直接使用。因此，开发者在编写 Java 应用程序时，应该尽量避免依赖于 `sun.misc.Launcher` 类及其相关的功能。
